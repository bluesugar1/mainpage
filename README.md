# 당근 통합 매물 검색기 (구/동 체크 없이 결과만 보기)

원하는 건 이거죠:
- 내가 구/동 일일이 체크 안 함
- 예: **서울** 선택하면 서울 전체 권역 매물을 자동으로 가져옴
- 링크만 주는 게 아니라 앱 안에 결과 목록을 바로 보여줌

이제 그렇게 동작합니다.

---

## 0) 지금 너 화면 기준으로 "다운로드" 하는 법 (PR Diff 화면)

네가 보낸 화면은 **PR의 Diff(변경점) 화면**이라서, 여기선 `Code → Download ZIP` 버튼이 바로 안 보여요.

### 방법 A (제일 쉬움): 왼쪽 위 뒤로가기(←)로 PR 나가기
1. 화면 **맨 위 왼쪽**에 있는 뒤로가기 화살표 `←` 클릭
2. 저장소 메인(파일 목록)으로 이동
3. 거기서 초록색 **Code** 버튼 클릭
4. **Download ZIP** 클릭

### 방법 B: 상단의 `mainpage` 텍스트 클릭
1. 화면 상단 제목 줄에 `mainpage`라고 써있는 텍스트 클릭
2. 저장소 메인으로 이동되면 **Code → Download ZIP**

### 방법 C: 이 화면에서 파일 하나씩 받기
1. 중앙 목록에서 `daangn_search_app.py` 클릭해서 펼치기
2. 우측 상단 `⋮`(점 세 개) 클릭
3. **파일 복사** 클릭 후 메모장에 붙여넣고 `daangn_search_app.py`로 저장
4. 같은 방식으로 필요한 파일들 저장

> C 방법은 번거롭기 때문에, 가능하면 A/B로 저장소 메인으로 가서 ZIP으로 한 번에 받는 걸 추천.

### 꼭 받아야 하는 파일
- `daangn_search_app.py` (데스크톱 앱 본체)
- `launch_web_app.bat` (Windows 원클릭 실행용)
- `launch_web_app.py` (웹 화면 자동 실행기)
- `index.html`, `app.js`, `styles.css` (웹 화면 파일)

## 0-1) 지금 네 화면(Codex 홈/아카이브)에서는 다운로드 버튼이 없음

네가 올린 마지막 스샷은 **저장소 화면이 아니라 Codex 홈(아카이브 목록) 화면**이라서,
거기에는 ZIP 다운로드 버튼이 원래 없습니다.

이 경우는 아래 순서로 가져와야 합니다.

1. `아카이브에 보관` 목록에서 프로젝트(`Create nationwide search feature for carrots`) 클릭
2. 우측 상단 `PR 만들기` 오른쪽의 `▼` 메뉴 클릭
3. `파일 복사` 또는 `패치 복사` 선택
4. 로컬 메모장에 붙여넣어 파일 저장

> 핵심: 홈 화면에서는 다운로드가 안 보이는 게 정상입니다. 반드시 프로젝트 상세(변경 파일 화면)로 들어가야 합니다.

## 1) 실행 방법 (가장 쉬운 방법)

### Windows
1. `launch_web_app.bat` 더블클릭 (웹 버전)
2. 또는 데스크톱 앱 실행:
   ```bash
   python daangn_search_app.py
   ```
   (안 되면 `py daangn_search_app.py`)

### macOS
```bash
python3 daangn_search_app.py
```

---

## 2) 사용 방법

1. 검색어 입력 (예: 자전거)
2. 도시 선택 (예: 서울)
3. `매물 가져오기` 클릭

그러면 선택한 도시 전체 권역 기준으로 결과가 표에 표시됩니다.

- 더블클릭: 해당 매물 열기
- `결과 복사`: 제목/가격/지역/링크 복사

---

## 3) CLI로 결과만 출력 (선택)

```bash
python3 daangn_search_app.py --keyword 자전거 --city 서울 --limit 30
```

위 명령은 서울 전체 권역 검색 결과를 터미널에 줄줄이 출력합니다.

---

## 참고
- 당근 공식 공개 API가 아니라 웹 페이지를 읽어 결과를 추출합니다.
- 사이트 구조가 바뀌면 파싱 로직 업데이트가 필요할 수 있습니다.
